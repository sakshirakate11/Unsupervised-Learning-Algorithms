# Unsupervised Learning Algorithms

This repository contains implementations of Unsupervised Machine Learning algorithms.

## Algorithms Implemented:
- KMeans Clustering
- 1. **K-Means Clustering**
   - Partitions data into K clusters
   - Uses centroid-based approach
   - Fast and efficient for large datasets

2. **K-Medoids Clustering**
   - Similar to K-Means but uses actual data points as centers
   - More robust to noise and outliers

3. **Hierarchical Clustering**
   - Builds a hierarchy of clusters
   - Can be Agglomerative (bottom-up) or Divisive (top-down)

4. **Customer Segmentation**
   thus is the dataset for the k medoids clustering.

4. **Q_Learning Algo**
  to implement the reinforcement learning algorithm.

5. **APRIORI ALGORITHM**
